# Premium-Izakaya 
This project provides restaurant menu application built with Python and FastAPI.

# Features
- Restaurant menu stored in JSON format
- FAST REST API
- Search dishes by name, ingredient, description, or category
- Simple HTML frontend
- Displays dish names, ingredients, descriptions, and prices
- No external AI service required

# Technologies
- Python
- FastAPI
- Uvicorn
- JSON
- HTML
- CSS
- JavaScript
